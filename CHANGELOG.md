# Changelog

## 0.3.0

- Rebrand the runtime as OwnMode Connect, with new CLI, configuration, native host and LaunchAgent identities; previous installations require explicit cleanup and new grants.

- Add a drag-to-Applications DMG for the universal macOS menu helper alongside the ZIP and npm tarball.
- Publish version-checked artifacts with checksums and release installation guidance.
- Publish publicly with anonymous HTTPS install commands, clear device/chat branding and real workspace evidence.
- Report the package version in health responses rather than a separately maintained version literal.

## 0.2.0

- Shared family identity, release-first installation and cross-project onboarding.
- Durable Chrome native messaging with bounded frames, cancellation and extension-only credentials.
- Opt-in transactional LaunchAgent startup, stable Node paths and actionable status/revocation handling.
- Universal macOS 13+ menu-bar controller with bundled runtime, explicit login-service restart and real status-item UI smoke.
- GitHub release tarball/menu-app artifacts and checksums; current pinned CI actions.

## 0.1.0

- Correct Apple streaming for extended Unicode sequences and report context-window and safety errors with actionable messages.
- Report unmatched revocations without modifying grants, and clean up streaming backpressure listeners.

- Initial local-only HTTP bridge, scoped origin grants, streaming Ollama, LM Studio and Apple Foundation Models providers.
